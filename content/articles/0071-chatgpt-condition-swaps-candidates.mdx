## 結論

ChatGPTに同じカテゴリ（SEO・GEOツール）の質問を、条件を足しながら投げました。モデルが検索する前にクエリへ書き込む候補ブランドを、2日間ぶん取り出して比べています。

条件が増えるたびに、候補が入れ替わっていました。

| 質問 | 候補に入ったブランド |
| --- | --- |
| 無条件 | Ahrefs / Semrush / Google Search Console / Screaming Frog |
| ＋「個人ブログでも使える」 | Google Search Console / **Ahrefs Webmaster Tools（無料版）** / Ubersuggest / Google Trends / ラッコキーワード |
| ＋「月1万円以内・日本語対応・個人事業主向け」 | ラッコキーワード / Nobilista / GMO順位チェッカー |

**無条件と3条件のあいだで、共通するブランドは1つもありませんでした。** SemrushとScreaming Frogは条件1つで消え、Ahrefsは有料の本体から無料版に置き換わり、最後にGoogle Search Consoleまで落ちて国産だけが残っています。

日をまたいでもう一度取ると、**入れ替わった質問と、1つも動かなかった質問に分かれました**。

これは2日間・5つの質問・1アカウントの記録です。「こう動くものだ」ではなく、**「この条件でこう動いた」という観測**として読んでください。

## 何を見たのか

ChatGPTは質問を受け取ると、自分で検索クエリを組み立てます。その中身が会話JSONに残ります。この記事が見ているのは、**モデルが1本目のクエリに書いたブランド名**です。

ユーザーは一度もブランド名を出していないのに、モデルは検索する前に製品名をクエリへ書き込みます。この挙動は[以前の記事](/articles/9)で扱った海外の調査と同じもので、今回は自分のログで確認しています。

条件は次のとおりです。

- ログイン状態、デスクトップWeb、モデルは `gpt-5-6`
- メモリ無効、カスタム指示は全項目を空
- 新規チャット。5つの質問を2日間、同じ条件で実行

使った5つの質問です。

1. `SEO対策のツールでおすすめを教えて`（無条件）
2. `個人ブログでも使えるSEOツールのおすすめは？`（条件1つ）
3. `月1万円以内・日本語対応・個人事業主向けのSEOツールを3つ挙げて`（条件3つ）
4. `2026年時点で最新のSEOツールのおすすめは？`（時点の指定）
5. `AI検索対策（GEO）のツールでおすすめを教えて`（新しいカテゴリ）

**先に断っておきます。** 2日間・5つの質問・1アカウントの記録です。割合の一般化には使えません。「この条件でこう動いた」という観測として読んでください。

段階ごとに何が起きていたかを分けて書きます。

**無条件 → 条件1つ。** SemrushとScreaming Frogが消えました。残ったのはGoogle Search Consoleだけで、Ahrefsは同じ会社のまま**有料の本体から無料版（Ahrefs Webmaster Tools）に置き換わって**います。代わりにUbersuggest・Google Trends・ラッコキーワードが入りました。残ったものに共通していたのは、**無料で使える枠がある**ことでした。

**条件1つ → 条件3つ。** Google Search Consoleも落ちました。残ったのはラッコキーワードだけで、Nobilista・GMO順位チェッカーが入っています。**海外の大手は1つも残っていません。**

「日本語対応」「月1万円以内」「個人事業主向け」の3つが揃うと、モデルが探しに行く先が国産ツールに切り替わっていました。実際、この質問で引用されたドメインも `rakkokeyword.com` `co.nobilista.com` `group.gmo` `kantan.gmo` と、すべて日本のドメインでした。

### 候補が変わると、引用されるサイトも変わる

候補入りは「回答に名前が載るか」だけの話ではありませんでした。**どのサイトが読まれ、引用されるか**も一緒に動いています。

無条件の質問では引用先が `developers.google.com` `ahrefs.com` `semrush.com` `screamingfrog.co.uk` でした。条件3つの質問では、そこに1つも重なりません。同じカテゴリの質問なのに、**読まれるページの集合ごと入れ替わっています**。

## 日をまたぐと、入れ替わった質問と動かなかった質問がある

同じ5つを翌日にもう一度実行しました。

| 質問 | 9/5 → 9/6 |
| --- | --- |
| 無条件 | **完全一致**（Ahrefs / Semrush / GSC / Screaming Frog） |
| ＋個人ブログ | **完全一致**（GSC / Ahrefs WMT / Ubersuggest / Trends / ラッコ） |
| 2026年時点 | 5つ一致、**SE Ranking が追加** |
| ＋月1万円・日本語 | ラッコ・Nobilista は一致、**ミエルカとRank Trackerが消え、GMO順位チェッカーが入る** |
| GEO（新カテゴリ） | Profound・Peec・Otterly は一致、**AthenaHQ が消え、Scrunch が入る** |

**英語圏の成熟したカテゴリは、日をまたいでも1つも動きませんでした。** 動いたのは、新しいカテゴリ（GEOツール）と、条件が細かい日本語の質問です。どちらも「定番」がまだ固まっていない領域です。

そして動き方には共通点がありました。**上位2〜3ブランドは動かず、4番目以降が入れ替わっている。** GEOならProfound・Peec・Otterlyが両日とも入り、4番目だけがAthenaHQからScrunchに変わりました。日本語の質問ならラッコキーワードとNobilistaが不変で、3つ目が入れ替わっています。

## 回答そのものも変わる

候補だけでなく、読者が見る回答も動きました。両日とも完走した3つの質問で比べます。

| 質問 | 9/5 | 9/6 |
| --- | --- | --- |
| ＋個人ブログ | GSC → ラッコ → Ahrefs → Trends → Ubersuggest | **完全一致（順序も）** |
| ＋月1万円・日本語 | ラッコ → Nobilista → **GMO AIかんたん集客** | ラッコ → Nobilista → **GMO順位チェッカー** |
| GEO | Profound → **Peec** → Ahrefs → Otterly → Semrush | **Otterly** → Profound → Semrush → Ahrefs → **Scrunch** |

GEOの質問では1番目がProfoundからOtterlyに変わり、9/6は「1つだけ選ぶならOtterlyAI」と断定しています。前日に2番目だったPeec AIは回答から消え、代わりにScrunchが入りました。

月1万円の質問では、3枠のうち1枠が別の製品に替わりました。同じGMOでも**AIかんたん集客から順位チェッカーへ**、ドメインも `kantan.gmo` から `rank-checker.com` に変わっています。

### 提示される価格まで変わる

同じラッコキーワードについて、こう書かれました。

- 9/5「有料プランは**月払いで1,320円〜**」
- 9/6「現行の月払いではエントリー**660円**、ライト990円」

660円は公式の年払い時の金額です。**9/6の「月払いでは660円」という記述は正しくない可能性が高い**。どちらも公式ページに載っている数字ですが、月払いと年払いのどちらを拾うかが日によって変わっていました。

自社の価格がAIにどう説明されているかは、一度確認する価値があります。

## この観測から言えること

- 同じカテゴリでも、条件を足すと候補ブランドが入れ替わった
- 無条件と条件3つのあいだで、共通するブランドは1つもなかった
- 候補が入れ替わると、引用されるドメインも入れ替わった
- 5つの質問のうち3つは、日をまたいでも候補が完全一致した
- 動いた2つは、新しいカテゴリと条件の多い日本語の質問だった
- 同じ製品の価格が、日によって違う金額で提示された

**2日間・5つの質問・1アカウントの記録です。** 同一プロンプトを再実行したときの引用元の重なりは32〜43%、ブランド名は日をまたぐと45〜59%という先行研究があります。**1回の結果で判断できません。**

## よくある質問

### 候補に入るブランドはどこで決まっているのですか

モデルが検索クエリを組み立てる時点です。ユーザーが名前を出していなくても、1本目のクエリに製品名が書き込まれています。検索はその候補を裏取りするために使われていました。つまり検索結果に載ることと、候補に入ることは別の関門です。

### 条件付きの質問を狙う意味はありますか

今回の観測では、無条件の質問と条件3つの質問で共通するブランドが1つもありませんでした。無条件の定番に割り込めなくても、条件付きの候補には別の枠があるということです。ただし2日間の観測なので、自社カテゴリで同じことが起きるかは自分で確かめてください。

### 何回測ればよいですか

最低でも日を分けて複数回です。今回、5つの質問のうち2つは翌日に候補が入れ替わりました。1回の結果を見て順位が動いたと判断すると、揺れを施策の効果と取り違えます。同一プロンプトの再実行でブランド名の重なりが45〜59%という先行研究もあります。

### 自社の価格が間違って説明されていたらどうすればよいですか

まず公式ページの料金表記を確認してください。今回の例では、月払いと年払いのどちらを拾うかが日によって変わり、片方は正しくない可能性の高い金額が提示されていました。月額の条件（年契約か月契約か、税込か税抜か）が1か所で明確に読み取れる書き方になっているかを見直すのが先です。

### 上位2〜3ブランドが固定なら、後発は無理ということですか

今回の観測ではそう見えた、というだけです。動いたのは新しいカテゴリと条件付きの質問で、いずれも4番目以降が入れ替わっていました。逆に言えば、**カテゴリの定義が新しいうちは入れ替わりが起きています**。GEOツールの質問では、2日間でAthenaHQが消えてScrunchが入りました。
