# 独自調査ハブによるGEO強化

技術的なクロール・構造化データ基盤は実装済みだが、公開83本のうち独自調査10本がニュース一覧に埋もれていた。
AI検索が二次要約ではなく、このサイトを引用元として選ぶ理由になる一次データを明示的に束ねる。

## ステップ

- [x] 公開記事と独自記事の比率を確認する
- [x] `/research` に独自記事だけの一覧を作る
- [x] CollectionPage / ItemList と公開・更新日を付ける
- [x] トップ、ヘッダー、回遊導線、sitemapから接続する
- [x] 型検査・テスト・lint・API検証・本番ビルド

## 判断

- robots、canonical、sitemap、Article / Organization / FAQ構造化データ、llms.txtは既に実装済み。追加タグではなく独自データの発見性を改善する。
- `/news` は一次情報へのリンク付きの要約を含む全記事アーカイブ、`/research` は自前の計測が結論の中心にある記事だけ、と役割を分ける。
- 独自記事の判定は既存frontmatterの `original: true` を唯一の情報源とし、一覧を手で二重管理しない。
