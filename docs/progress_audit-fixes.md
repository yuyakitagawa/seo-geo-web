# ページ診断の見直し（2026-09-06）

利用者からの指摘を受けて、判定の出し分け・根拠・結果表示を直す。

## 1. 判定の出し分けと根拠の差し替え
- [x] ページの種類（記事／一覧／法務／フォーム）を分類する関数を audit.ts に追加
- [x] faq「質問と回答の形式がありません」: 一覧・法務・フォームと短いページでは出さない。FAQリッチリザルトは 2026-05-07 に廃止されたので faq-jsonld は削除
- [x] geo-quotation「原文をそのまま引用した箇所がありません」: 一覧・法務・フォーム、および外部出典が1本も無いページ（citation で指摘済み）では出さない
- [x] date「公開日・更新日が機械可読になっていません」: 記事系ページだけに出す。根拠を Google の byline date ドキュメントに差し替える
- [x] heading-order「見出しの階層が飛んでいます」: Googleは「順序が違っても検索には関係ない」と明記しているのでSEOの指摘から外し、アクセシビリティ（W3C WAI）の項目にする
- [x] organization「運営者が構造化データにありません」: Googleは「ホームページか会社紹介ページ1枚でよい。全ページに入れる必要はない」と書いているので、トップと運営者紹介ページだけで判定する
