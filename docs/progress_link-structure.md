# 追記2: 「何クリック以内」の根拠を切り分ける

「重要ページは数クリック以内」はGoogleも言っている、という指摘を受けて一次情報を確認した。
確認できたのは次の3つで、**クリック数の数字はどの文書にも無い**。

- 「Importance of link architecture」（検索セントラル ブログ, 2008-10-07）:
  「重要なページはトップページからクリックでき、サイト全体を通じてGooglebotが見つけやすい状態にしてください」
  （検索エンジンのクローラーが検索ボックスに入力したりプルダウンメニューをたどったりすることはまれ、という理由つき）
- サイトマップのドキュメント（現行）: サイトマップが無くてもよい条件の1つとして
  「サイト内が十分にリンクされている＝Googlebotがトップページからリンクをたどって重要なページをすべて見つけられる」
- ECサイトのドキュメント（現行）: 到達までにたどるリンクの本数・そのページに向けられたリンクの本数を
  相対的な重要度の推測に使うことがある

## ステップ
- [x] SOURCES に `linkArchitecture`（2008年のブログ）を追加し、レッスン07の sources に入れる
- [x] レッスン07に「「何クリック以内」はGoogleが決めているのか」（`#clicks`）を新設
      （出典3件の表＋`FigureCompare` で「Googleが述べていること／当サイトが決めた目安」を分ける）
- [x] 階層の図・型3の図のキャプションから、この節へ送る
- [x] 到達目標・FAQ（重要なページは何クリック以内に置くべきですか）・所要時間（20→22分）を更新
- [x] README 更新
- [x] `npm run typecheck && npm run build`
- [x] ライト／ダーク・PC／スマホで表示確認

## 判断メモ
- 「few clicks」という言い回しは二次情報の要約には出てくるが、Googleの原文で確認できたのは
  「clickable from the home page」まで。訳文は確認できた範囲に寄せ、「数クリック以内」とは書かない。
- 2008年のブログは古いので、出典ラベルに年を入れて読者が鮮度を判断できるようにする
  （現行ドキュメント2件と並べることで、同じことが今も書かれていると示す）。
- egress制限で developers.google.com を直接取得できないため、原文は検索経由で複数回突き合わせて確認した。
