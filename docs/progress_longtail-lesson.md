# 進捗: 教科書にロングテール設計のレッスンを追加

## 目的
`/learn`（SEO・GEO教科書）に「ロングテールを面で押さえる」レッスンを1本足す。
レッスン03「検索意図とキーワード設計」が**1本ずつページを決める**話で終わっているため、
その次に来るべき**クエリ空間を面で埋める**話が教科書に無い。

GEO側の理由も同じレッスンで扱う。Googleは AI による概要と AI モードが
「クエリ ファンアウト」（1つの質問を複数のサブトピックに分解して検索する手法）を
使う場合があると説明しており、細かい質問に個別に答えているページほど
サブクエリ側で当たる。ロングテールはSEOの話であると同時にGEOの話になる。

## 方針
- 新レッスンは **Level 1 / order 04 / slug `long-tail`**。レッスン03の直後に入れる。
- 既存レッスン04〜10は order が1つずつ後ろにずれる（**slug・URLは変えない**ので外部リンクは切れない）。
- 本文に埋め込まれた「レッスン04」などの**表記だけ**を追従させる。
- 数値は書かない。Google公式で確認できる記述と、当サイトの整理であることを明示した図表だけで構成する。
- 特定サービスの事例は載せない（`src/lib/cases.ts` の収録条件を満たす一次情報が無いため）。
