# Figmaのデザインシステム化

`src/app/globals.css` のトークンを正として、Figma側に変数・スタイル・コンポーネントを作る。

## 決めたこと

- **ローカルプラグイン（`figma-plugin/`）を正の手段にする**。MCP（Figmaのリモート実行）は同じ Plugin API の
  JSを外から流し込む仕組みだが、プランごとのツールコール上限がある。2026-09-21 に Starter の上限に当たり、
  トップページの組み立てが1回目の書き込みで中断した。ローカルプラグインなら実行回数は無制限。
- **ライト/ダークは別コレクション**。無料プランは1コレクション1モードまで（`addMode` が
  `Limited to 1 modes only`）。Professional以上に上げたら1コレクション2モードへ統合する。
- **画面（トップページ）のFigma化は後回し**。まずデザインシステム（変数・スタイル・部品）を土台として入れる。

## 削った結果（2026-09-25）

使用回数を数えて決めた。`grep` で数えた実数であって、好みではない。

| 対象 | 使用箇所 | 判断 |
| --- | --- | --- |
| `Container`（部品） | 0 | 削除 |
| `Chip`（部品） | 0（`CHIP` クラスは10箇所） | 部品だけ削除、クラスは残す |
| `SectionHeading`（部品） | 0 | 削除 |
| `CHIP_ON_INK` | 0 | 削除 |
| `ContainerWidth` 型 | 0（`Container` 削除で用済み） | 削除 |
| 汎用 `Card`（Figma） | — | 廃止。`ArticleCard` に置き換え |

**色トークンは1つも削れなかった。** 17個すべてコードで使われている
（`mute` 158 / `accent` 100 / `paper` 71 / `news` 40 / `ink` 36 / `line` 36 / `invert` 27 / `accent-ink` 20 /
`fg` 16 / `geo` 15 / `line-strong` 15 / `fill` 12 / `seo` 11 / `fill-strong` 7 / `canvas` 6 / `surface` 3）。
減らすなら見た目が変わる統合になる（候補: `line-strong`→`line`、`fill-strong`→`fill`）。
入力欄の輪郭と弱いバッジの地という別の役割を潰すことになるので、指示があるまでやらない。

**`BADGE.md` は消しかけて戻した。** 静的な grep では0件だが、記事ページが `size="md"` を渡して
`BADGE[size]` で動的に引いていた。動的インデックスは grep に映らない（`npm run typecheck` が捕まえた）。

モックは構造と呼び出し順しか見ていない。実機では次を目で確認する。
