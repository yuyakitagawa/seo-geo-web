# 薄いタグページへのSEO評価分散を抑える

公開HTMLとタグ構成を確認し、検索結果として固有価値の薄い一覧ページへの評価分散を抑える。

## ステップ

- [x] 全ページの title・description・canonical・h1 重複を検査
- [x] タグごとの公開記事数を集計
- [x] タグページのインデックス足切りを2本から3本へ変更
- [x] 型検査・テスト・lint・API検証・本番ビルド

## 判断

- title・description・canonical・h1は、公開対象ページで欠落・重複なし。既に整っているため変更しない。
- 公開記事74本に対してタグは201個あり、1記事だけが147個、2記事だけが25個。2記事の一覧も検索結果としての固有価値が薄いため、3記事以上のタグだけをインデックス対象にする。
- 足切り未満のページも `noindex, follow` で残し、読者とクローラーがリンクを辿れる状態は維持する。
