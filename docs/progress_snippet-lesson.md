# 進捗: 教科書レッスン07「スニペットの役割と対策」

検索結果のスニペット・強調スニペット・AIによる概要での引用を、
「本文の一部を抜き出して見せる」同じ仕組みとして1章にまとめる。
既存のレッスン06（本文の書き方）が「抜き出されやすい文を書く」担当なのに対し、
このレッスンは「書いた本文が実際にどう扱われ、サイト側からどこまで介入できるか」を担当する。

出典はGoogle検索セントラルの公開ドキュメント（スニペットを管理する／強調スニペットとウェブサイト／
robots meta タグ・data-nosnippet・X-Robots-Tag の設定／AI機能とウェブサイト／生成AI機能向けの最適化ガイド／
タイトルリンクを管理する）、Search Consoleヘルプ（検索パフォーマンス レポート）、GEO論文（arXiv:2311.09735）のみ。
Googleが書いていない整理（3種類の並べ方、事故の形、原因と対処の対応づけ）は、その旨をキャプションに明記した。

## 設計
- slug は `snippet`、order 7、レベル2（実装）。レッスン06の直後に置き、既存の07〜13を08〜14に繰り下げ（全14レッスン）
- 章の構成は「役割 → 生成元 → meta description → 制御 → AIへの影響 → 本文の整え方 → 計測」の7節
- 番号はすべて `lessonNo(slug)` 経由なので、繰り下げで直す本文表記は無い

## 決めたこと
- **meta descriptionは独立した1節にする**。「本文が主・descriptionは補助」で1行に畳むと、
  唯一こちらから文言を提案できる枠だという実務上の重さが落ちる。
  「書く価値がある側」と「期待しすぎてはいけない側」を2枚のカードで並べ、
  優先順位は「本文の整備が先、descriptionは後」と明示した。
- **nosnippet はAI対策として使えない**ことを中心に置く。Googleは、AIによる概要とAIモードに
  リンクとして出る対象になるにはスニペット付きで表示できる状態が必要だと説明しており、
  nosnippet はAI機能と通常の検索結果を同時に止める。AI機能だけを止める指定は無い。
- チャンク化・AI専用ファイル・強調スニペット用マークアップは「やらなくていいこと」に置く
  （前者2つはGoogleが不要と明記、3つ目は存在しない）。
