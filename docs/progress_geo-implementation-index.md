# /learn/geo-implementation が「クロール済み - インデックス未登録」になった件

## 何が起きているか（2026-09-07 時点）
Search Console で `https://seo-geo-lab.com/learn/geo-implementation` が
「クロール済み - インデックス未登録」に分類された。

技術的な障害は無い（実ページのHTMLを取得して確認）:
- `<link rel="canonical">` は自己参照で正しい
- `<meta name="robots" content="index, follow">`
- title / description / h1 / JSON-LD（Article + LearningResource）すべて出ている
- sitemap にも入っている

つまり Google は「読めなかった」のではなく「載せる価値が無いと判断した」。
原因は次の2つ。

### 原因1（主因）: `/geo` との重複
`/geo`（GEO対策とは、本文21,222字）が、このレッスン（本文10,382字）の中身を
ほぼ丸ごと先に持っている。同じサイト内で同じ問いに2ページが答えていて、
Google は強いほう（`/geo`。ヘッダーナビにあり、記事37本からリンクされている）を残し、
弱いほう（このレッスン）を落としている。

| 重複している内容 | /geo の場所 | レッスンの場所 |
|---|---|---|
| AIクローラーの一覧と「拒否すると何が起きるか」 | `#crawlers`（10行のベタ書き表） | `#crawlers`（crawlers.ts の14種） |
| 公式IPレンジでのなりすまし確認 | `#bots` の h3「Botの名乗りは自己申告」 | `#verify`（このレッスン最大の独自要素） |
| 引用されやすい書き方（DoDont） | `#writing` | `#notneeded` / `#shape` |

`/geo` の10行の表は `src/lib/crawlers.ts`（14種・verified付き）のベタ書き複製でもあり、
「同じデータを2か所に書かない」という規約にも反している。

### 原因2: このページに「そこにしか無い情報」が出ていない
本文が公式ドキュメントの再構成に留まっていて、情報の増分が無い。
一方でこのサイトは、まさにこのレッスンの主張を裏づける自前の実測記事を持っているのに
1本もリンクしていない:
- `/articles/39` Googlebotを名乗るリクエストの27.5%がIP範囲外だった（`#verify` の裏づけ）
- `/articles/38` llms.txt は29日間・AIクローラー1万9,347件で0回しか読まれなかった（`#notneeded` の裏づけ）
- `/articles/37` クローラーはsitemap順に巡回していない（実ログ19万件）

補足: このページの公開は 2026-08-30 で、まだ8日しか経っていない。
新規サイトの新規ページが数週間この分類に入るのは通常の挙動でもある。
以下はその「様子見」の期間に、載せる価値の側を上げておくための作業。
