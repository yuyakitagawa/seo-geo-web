# 進捗: 見出しと本文の噛み合いを診断に足す

見出しごとに、その下の本文と噛み合っているかを見る判定を足す。
AI検索は見出しごとのまとまり（パッセージ）を抜き出して回答に使うので、見出しが中身を
言い当てていないと、その見出しで拾われても答えになっていない、ということが起きる。

## 決めたこと
- **判定の主軸は「見出しの重要語が本文に出てくるか」**。見出しと本文の近さ（TF-IDFのコサイン類似度）も
  計算して結果に載せるが、**判定には使わない**。
  「近さ0.12」と言われても直しようがないが、「見出しの語が本文に1つも無い」なら直し方が一意に決まる。
  **廃止した `/tools/prompt-fit` が読み手に刺さらなかったのは、この種の数値を前に出していたからだと見ている**。
  同じ失敗を繰り返さない。
- **誤検知を出さない除外を先に決める**。「まとめ」「はじめに」などの定型の見出しと、本文が120字未満の節は
  判定しない。語が重ならないのが当たり前で、直す必要のない指摘が並ぶ。
- **解析の部品は `promptFit.ts` と共有する**（見出しブロック分割・分かち書き・TF-IDF・重要語・文の分割）。
  判定を2か所に書かない。廃止したツールの本体がここで活きた。
- **新しいツールは作らない**。ページ診断の指摘（`heading-fit`）として出せば、サイト修正提案書にも
  自動で束ねられて載る。
